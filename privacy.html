Privacy Policy

Hermes Drive · last updated 10 November 2026

Who this covers

Hermes Drive is a single-user application. Its only user is the individual who owns it and who authorised it against their own Google account. It has no other users, no sign-up, and is not offered to the public.

What data the application accesses

With the owner's explicit consent through Google's standard authorisation screen, the application may access:

  • Google Drive — to read document templates, create folders, and save the documents it produces into the owner's own folders.
  • Google Sheets — to read and update reference data such as event names, sponsor names and speaker records held in the owner's own spreadsheets.
  • Google Docs — to read the text of the owner's own documents.

The application accesses only files belonging to, or shared with, the account that authorised it. It does not access any other person's data.

How the data is used

Only to carry out the task the owner asked for: producing a document, filing it in the correct folder, or checking a value against the owner's own reference data. The data is processed in memory while that task runs, and the finished documents are written back to the owner's own Google Drive.

How the data is stored

The application runs on a private server controlled by the owner. Authorisation tokens issued by Google are stored on that server with file permissions restricted to the owner, and are used only to call Google's APIs on the owner's behalf. Working copies of files are temporary and are removed once a task is finished.

Sharing

No data obtained from Google is sold, rented, traded, published, or disclosed to any third party. No advertising, profiling, or analytics is performed on it. No human other than the owner has access to it.

Limited Use: this application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The application keeps no database of Google user data. Documents it produces remain in the owner's own Google Drive, under the owner's control, and can be deleted there at any time. The owner can revoke the application's access at any moment from Google Account permissions, which immediately ends all access.

Children

The application is not directed at children and collects no data from them.

Changes

If this policy changes, the updated version will be published on this page with a new date at the top.

Contact

Questions about this policy can be sent to the application owner at the support email address shown on the Google authorisation screen for this application.
